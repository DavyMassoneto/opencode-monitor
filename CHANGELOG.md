# Changelog

Notable changes in each version. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and versions follow [SemVer](https://semver.org/). Generated by the release workflow with [git-cliff](https://git-cliff.org).

## [0.3.0] - 2026-11-27

### Features

- Support Windows with PowerShell (8f1297d)
## [0.2.0] - 2026-11-27

### Features

- Retry failed notices, verify process identity and make limits configurable (9cfaf6a)
- Add stderr files, capture_stderr, cwd and env to monitors (d6917f1)
- Add wake, queue, silent and manual delivery modes and monitor_fetch (e903768)
- Add timeout_ms and persistent monitors, expiry notices and the history of finished monitors (c9a5f96)
- Add monitor_list and monitor_stop, limit monitors per session and stop them when the session is deleted (447d330)
- Filter, batch, clean and redact monitor lines and stop flooding commands (207689c)
- Add monitor_start, delivering each output line as a synthetic notice (28edbf0)

### Bug Fixes

- Tolerate files removed by another plugin instance when pruning and logging (a0f3d95)
- Check shell permission for every subcommand of a monitor command (1886142)

### Maintenance

- Drive steady output with timers so slow runners do not time out (370cc3b)
- Document the tools, safety, options and delivery retries (b4ebcf1)
- Cover dev server, fake CI, dying command and malicious output scenarios (4371253)
- Adopt the fenix rules, standards and architecture (cb55836)
